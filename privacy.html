수집하지 않는 것

현재 HeightCue 사이트는 회원가입, 댓글, 이메일 수집 기능을 운영하지 않습니다. 아동의 이름·나이·키·사진 등 개인정보 입력란도 없습니다.

외부 링크

외부 사이트에는 해당 서비스의 개인정보처리방침이 적용됩니다.

익명 제휴 클릭 집계

미국 Amazon 제휴 링크를 누르면 일회성 무작위 이벤트 번호, 제품 식별자, 시장, 사이트 내부 경로, 이동할 사이트의 도메인, 서버 기록 시각을 저장합니다. IP 주소, 쿠키, 사용자 에이전트, 유입 경로, 전체 목적지 URL, 영구 방문자 식별자, 아동 정보는 저장하지 않습니다. 집계 목적은 콘텐츠에서 제휴 링크까지의 전환 흐름을 확인하는 것입니다.

Anonymous affiliate-click counting

When a U.S. Amazon affiliate link is opened, HeightCue records a one-time random event ID, product ID, market, internal source path, destination domain, and server timestamp. It does not store IP addresses, cookies, user agents, referrers, full destination URLs, persistent visitor IDs, or child data.

웹 애널리틱스

사이트 이용 통계에 Google Analytics(GA4)를 사용할 수 있으며, IP 익명화가 적용되어 있습니다. 광고 타기팅 및 유사잠재고객 생성에는 사용하지 않습니다.

분석 원칙

아동 건강정보를 광고 타기팅이나 유사잠재고객 생성에 사용하지 않습니다.
